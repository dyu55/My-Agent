太棒了！为一个家庭记账网页搭建框架是一个很好的开始，而且你要求将结构、样式和逻辑分离，这正是良好的编程习惯。

我将为你创建三个文件：`index.html` (页面结构), `style.css` (样式), 和 `script.js` (逻辑)。

### 1. 项目设置

首先，请在你电脑上创建一个新文件夹，比如叫做 `family_budget_app`。
在这个文件夹里，创建三个空文件，并分别命名为：
*   `index.html`
*   `style.css`
*   `script.js`

### 2. `index.html` (页面结构)

这个文件定义了你的网页内容和布局。我们将包含一个标题、一个添加交易的表单、一个收支概览和一个交易列表。

将以下代码复制并粘贴到你的 `index.html` 文件中：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>家庭记账本</title>
    <!-- 链接到样式文件 -->
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="container">
        <h1>家庭记账本</h1>

        <div class="summary-section">
            <h2>账户总览</h2>
            <div class="balance-info">
                <p>总收入: <span id="total-income" class="income">¥ 0.00</span></p>
                <p>总支出: <span id="total-expense" class="expense">¥ 0.00</span></p>
                <p>当前余额: <span id="current-balance">¥ 0.00</span></p>
            </div>
        </div>

        <div class="add-transaction-section">
            <h2>添加新交易</h2>
            <form id="transaction-form">
                <div class="form-group">
                    <label for="description">描述:</label>
                    <input type="text" id="description" placeholder="例如：买菜、发工资" required>
                </div>
                <div class="form-group">
                    <label for="amount">金额:</label>
                    <input type="number" id="amount" step="0.01" min="0" placeholder="0.00" required>
                </div>
                <div class="form-group">
                    <label for="type">类型:</label>
                    <select id="type">
                        <option value="income">收入</option>
                        <option value="expense">支出</option>
                    </select>
                </div>
                <button type="submit">添加交易</button>
            </form>
        </div>

        <div class="transaction-list-section">
            <h2>交易记录</h2>
            <ul id="transaction-list">
                <!-- 交易将在这里动态添加 -->
                <li class="transaction-item income">
                    <span>初始资金</span>
                    <span class="amount">+ ¥ 1000.00</span>
                    <button class="delete-btn">X</button>
                </li>
                 <li class="transaction-item expense">
                    <span>买菜</span>
                    <span class="amount">- ¥ 50.00</span>
                    <button class="delete-btn">X</button>
                </li>
            </ul>
        </div>
    </div>

    <!-- 链接到JavaScript文件，defer属性确保HTML解析完成后再执行脚本 -->
    <script src="script.js" defer></script>
</body>
</html>
```

**代码解释：**
*   `<head>` 部分包含页面的元信息，最重要的就是通过 `<link rel="stylesheet" href="style.css">` 链接到了你的样式文件。
*   `<body>` 是网页的主要内容。
*   `<div class="container">` 用于包裹所有内容，方便居中和设置最大宽度。
*   `<h1>` 是主标题。
*   `summary-section` 包含总收入、总支出和当前余额。
*   `add-transaction-section` 包含一个表单，用于输入交易描述、金额和类型。
*   `transaction-list-section` 是一个无序列表 `<ul>`，将来我们会用JavaScript在这里添加新的交易记录。我添加了两个示例交易，以便你看到样式效果。
*   `<script src="script.js" defer></script>` 在 `</body>` 标签关闭前引入你的 JavaScript 文件。`defer` 属性很重要，它告诉浏览器在HTML内容完全加载和解析后再执行脚本，避免因为脚本尝试操作尚未存在的DOM元素而出错。

**代码解释：**
*   我们设置了全局的 `body` 样式，包括字体、背景色、文本颜色等。
*   `.container` 类用于限制内容宽度并使其居中，增加了圆角和阴影，看起来更像一个卡片。

*   `#transaction-list` 中的 `transaction-item` 使用了 `flexbox` 布局，让描述、金额和删除按钮水平排列并分散对齐。
*   `income` 和 `expense` 类用于不同颜色显示收入和支出金额，增强视觉区分。

### 4. `script.js` (逻辑)

现在，这个文件还不会做太多事情，因为你只要求搭好框架。我们只添加一个简单的 `console.log` 来确认 JavaScript 文件被成功加载和执行，并演示如何获取一个HTML元素。

将以下代码复制并粘贴到你的 `script.js` 文件中：

```javascript
// script.js

// 页面加载完成后执行此函数
document.addEventListener('DOMContentLoaded', () => {
    console.log('JavaScript 文件已成功加载！');
    console.log('记账网页框架搭建完成，等待后续逻辑开发。');

    // 示例：获取表单元素，虽然现在还没用到它的提交事件
    const transactionForm = document.getElementById('transaction-form');
    if (transactionForm) {
        console.log('成功获取到交易表单元素。');
        // 可以添加一个简单的事件监听器来测试
        transactionForm.addEventListener('submit', (event) => {
            event.preventDefault(); // 阻止表单默认提交行为（页面刷新）
            console.log('表单被提交了！(目前只是打印信息，没有实际处理)');
            // 未来这里会处理表单数据，添加新交易
        });
    }

    // 示例：获取交易列表，未来会将新交易添加到这里
    const transactionList = document.getElementById('transaction-list');
    if (transactionList) {
        console.log('成功获取到交易列表元素。');
    }

    // 示例：获取余额显示元素
    const currentBalanceSpan = document.getElementById('current-balance');
    if (currentBalanceSpan) {
        console.log('成功获取到当前余额显示元素。');
    }
});
```

**代码解释：**
*   `document.addEventListener('DOMContentLoaded', ...)` 确保当HTML文档完全加载和解析后才执行JavaScript代码。这是一个好习惯，可以避免脚本尝试操作尚未加载的HTML元素。
*   `console.log()` 语句会在浏览器的开发者工具控制台中输出信息，这是调试JavaScript的常用方法。
*   我们通过 `document.getElementById()` 获取了一些HTML元素，这展示了JavaScript如何与页面元素进行交互。
*   为 `transactionForm` 添加了一个 `submit` 事件监听器，并使用了 `event.preventDefault()` 来阻止表单默认的页面刷新行为，这在单页应用中很常见。

### 5. 如何查看你的网页

1.  **保存所有文件：** 确保你已经保存了 `index.html`, `style.css`, 和 `script.js` 这三个文件。
2.  **打开 `index.html`：** 找到你创建的 `family_budget_app` 文件夹，然后双击 `index.html` 文件。它应该会在你的默认网页浏览器中打开。

你现在应该能看到一个带有标题、账户总览、添加交易表单和交易记录列表的基本布局，并且已经应用了我们设置的样式。

### 6. 检查JavaScript是否工作

1.  在浏览器中打开你的网页。
2.  按下 `F12` 键（或右键点击页面，选择“检查”/“检查元素”），打开开发者工具。
3.  点击“控制台”（Console）标签页。
4.  你应该能看到我们 `script.js` 文件中打印的几条信息，例如：“JavaScript 文件已成功加载！”。
5.  尝试点击“添加交易”按钮，控制台应该会打印“表单被提交了！(目前只是打印信息，没有实际处理)”。

这样，你就成功搭建了一个三文件分离的家庭记账网页基本框架！接下来，我们可以逐步添加更复杂的逻辑，比如真正地添加交易、计算余额、存储数据等。
