This is a clean, modular starting point for your Family Finance Tracker. I have included a form to add data and a summary section to track your balance.

### 1. index.html
This file defines the structure. It includes a header, a summary section for totals, a form for input, and a container where the records will be injected.

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Family Finance Tracker</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <div class="container">
        <h1>Family Finance Tracker</h1>

        <!-- Summary Section -->
        <div class="summary">
            <div class="card">
                <h3>Balance</h3>
                <p id="total-balance">$0.00</p>
            </div>
            <div class="card income">
                <h3>Income</h3>
                <p id="total-income">$0.00</p>
            </div>
            <div class="card expense">
                <h3>Expenses</h3>
                <p id="total-expense">$0.00</p>
            </div>
        </div>

        <!-- Input Form -->
        <div class="form-container">
            <h3>Add New Record</h3>
            <form id="finance-form">
                <input type="text" id="description" placeholder="Description (e.g. Groceries)" required>
                <input type="number" id="amount" placeholder="Amount" step="0.01" required>
                <select id="type">
                    <option value="income">Income</option>
                    <option value="expense">Expense</option>
                </select>
                <button type="submit">Add Transaction</button>
            </form>
        </div>

        <!-- Records List -->
        <div class="list-container">
            <h3>Transaction History</h3>
            <ul id="transaction-list">
                <!-- Records will appear here dynamically -->
                <p class="empty-msg">No records found. Start adding some!</p>
            </ul>
        </div>
    </div>

    <script src="app.js"></script>
</body>
</html>
```

### 3. app.js
This file contains the logic to handle the form submission, calculate the totals, and update the list on the screen.

```javascript
// State management
let transactions = [];

// DOM Elements
const form = document.getElementById('finance-form');
const descriptionInput = document.getElementById('description');
const amountInput = document.getElementById('amount');
const typeInput = document.getElementById('type');
const list = document.getElementById('transaction-list');

const balanceDisplay = document.getElementById('total-balance');
const incomeDisplay = document.getElementById('total-income');
const expenseDisplay = document.getElementById('total-expense');

// Function to update the UI
function updateUI() {
    // Clear list
    list.innerHTML = '';

    if (transactions.length === 0) {
        list.innerHTML = '<p class="empty-msg">No records found. Start adding some!</p>';
    }

    let totalIncome = 0;
    let totalExpense = 0;

    transactions.forEach((transaction, index) => {
        const amount = parseFloat(transaction.amount);
        
        // Calculate totals
        if (transaction.type === 'income') {
            totalIncome += amount;
        } else {
            totalExpense += amount;
        }

        // Create list item
        const li = document.createElement('li');
        li.classList.add('transaction-item', transaction.type);
        li.innerHTML = `
            <span>${transaction.description}</span>
            <span>${transaction.type === 'income' ? '+' : '-'}$${amount.toFixed(2)}</span>
        `;
        list.appendChild(li);
    });

    const totalBalance = totalIncome - totalExpense;

    // Update Summary numbers
    balanceDisplay.innerText = `$${totalBalance.toFixed(2)}`;
    incomeDisplay.innerText = `$${totalIncome.toFixed(2)}`;
    expenseDisplay.innerText = `$${totalExpense.toFixed(2)}`;
}

// Handle Form Submission
form.addEventListener('submit', (e) => {
    e.preventDefault();

    const newTransaction = {
        description: descriptionInput.value,
        amount: amountInput.value,
        type: typeInput.value
    };

    transactions.push(newTransaction);
    
    // Reset form
    form.reset();
    
    // Refresh UI
    updateUI();
});

// Initialize
updateUI();
```

### How to run this:
1. Create a folder on your computer.
2. Save the three blocks of code above as `index.html`, `style.css`, and `app.js` inside that folder.
3. Double-click `index.html` to open it in your web browser.
