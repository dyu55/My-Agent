Since you don't know how to code, the best way to start is by using a **"Frontend-First" approach**. We will create a web app using HTML, CSS, and JavaScript. 

To keep it simple, we will use your browser's **Local Storage**. This means your data is saved directly on your computer's browser, so you don't have to worry about setting up complex databases or servers right now.

Here is your step-by-step guide to building your first app.

---

### Step 1: Install Your Tools
You only need two things to start:
1.  **A Web Browser:** (You already have this—Chrome, Firefox, or Edge).
2.  **A Code Editor:** Download and install **[Visual Studio Code (VS Code)](https://code.visualstudio.com/)**. It is free and the industry standard.

---

### Step 2: Set Up Your Project Folder
1.  Create a new folder on your desktop and name it `finance-tracker`.
2.  Open **VS Code**.
3.  Go to `File` $\rightarrow$ `Open Folder...` and select the `finance-tracker` folder you just created.
4.  Create a new file inside that folder by clicking the "New File" icon and name it exactly: **`index.html`**

---

### Step 3: The Code
Since you are a beginner, I have combined the structure (HTML), the styling (CSS), and the logic (JavaScript) into **one single file**. 

**Copy the entire block of code below and paste it into your `index.html` file in VS Code:**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Finance Tracker</title>
    <style>
        :root {
            --primary: #2ecc71;
            --danger: #e74c3c;
            --dark: #2c3e50;
            --light: #f4f7f6;
        }
        body {
            font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
            background-color: var(--light);
            display: flex;
            justify-content: center;
            padding: 20px;
        }
        .container {
            width: 100%;
            max-width: 400px;
            background: white;
            padding: 2rem;
            border-radius: 15px;
            box-shadow: 0 10px 25px rgba(0,0,0,0.1);
        }
        h2 { text-align: center; color: var(--dark); }
        .balance-card {
            text-align: center;
            background: var(--dark);
            color: white;
            padding: 1.5rem;
            border-radius: 10px;
            margin-bottom: 20px;
        }
        .balance-amount { font-size: 2rem; font-weight: bold; }
        
        form { display: flex; flex-direction: column; gap: 10px; }
        input, select {
            padding: 10px;
            border: 1px solid #ddd;
            border-radius: 5px;
            font-size: 1rem;
        }
        button {
            padding: 10px;
            background: var(--primary);
            color: white;
            border: none;
            border-radius: 5px;
            cursor: pointer;
            font-weight: bold;
            font-size: 1rem;
        }
        button:hover { opacity: 0.9; }

        .transaction-list {
            margin-top: 20px;
            list-style: none;
            padding: 0;
        }
        .transaction-item {
            display: flex;
            justify-content: space-between;
            background: #fff;
            padding: 10px;
            border-bottom: 1px solid #eee;
            border-left: 5px solid #ccc;
        }
        .transaction-item.income { border-left-color: var(--primary); }
        .transaction-item.expense { border-left-color: var(--danger); }
        .delete-btn {
            color: var(--danger);
            cursor: pointer;
            font-weight: bold;
            margin-left: 10px;
        }
    </style>
</head>
<body>

<div class="container">
    <h2>💰 Finance Tracker</h2>
    
    <div class="balance-card">
        <div>Your Balance</div>
        <div class="balance-amount" id="balance">$0.00</div>
    </div>

    <form id="transaction-form">
        <input type="text" id="text" placeholder="What was this for?" required>
        <input type="number" id="amount" placeholder="Amount (e.g. 50 or -20)" required>
        <select id="type">
            <option value="income">Income</option>
            <option value="expense">Expense</option>
        </select>
        <button type="submit">Add Transaction</button>
    </form>

    <ul class="transaction-list" id="list">
        <!-- Transactions will appear here -->
    </ul>
</div>

<script>
    const balance = document.getElementById('balance');
    const list = document.getElementById('list');
    const form = document.getElementById('transaction-form');
    const text = document.getElementById('text');
    const amount = document.getElementById('amount');
    const type = document.getElementById('type');

    // Load data from LocalStorage
    let transactions = JSON.parse(localStorage.getItem('transactions')) || [];

    function updateValues() {
        const total = transactions.reduce((acc, item) => {
            return item.type === 'income' ? acc + item.amount : acc - item.amount;
        }, 0);
        
        balance.innerText = `$${total.toFixed(2)}`;
    }

    function addTransactionDOM(transaction) {
        const item = document.createElement('li');
        item.classList.add('transaction-item', transaction.type);
        
        item.innerHTML = `
            ${transaction.text} <span>${transaction.type === 'income' ? '+' : '-'}$${transaction.amount.toFixed(2)} 
            <span class="delete-btn" onclick="removeTransaction(${transaction.id})">x</span></span>
        `;
        
        list.appendChild(item);
    }

    function removeTransaction(id) {
        transactions = transactions.filter(t => t.id !== id);
        localStorage.setItem('transactions', JSON.stringify(transactions));
        init();
    }

    function init() {
        list.innerHTML = '';
        transactions.forEach(addTransactionDOM);
        updateValues();
    }

    form.addEventListener('submit', (e) => {
        e.preventDefault();
        
        const transaction = {
            id: Math.floor(Math.random() * 1000000),
            text: text.value,
            amount: parseFloat(amount.value),
            type: type.value
        };

        transactions.push(transaction);
        localStorage.setItem('transactions', JSON.stringify(transactions));
        
        addTransactionDOM(transaction);
        updateValues();
        
        text.value = '';
        amount.value = '';
    });

    init();
</script>

</body>
</html>
```

---

### Step 4: How to Open it in Your Browser
1.  Save the file in VS Code (`Ctrl + S` or `Cmd + S`).
2.  Go to your `finance-tracker` folder on your desktop.
3.  **Double-click `index.html`**.
4.  It will open in your default web browser. You now have a working finance tracker!

---

### Step 5: How to put it on the Internet (For Free)
Right now, the app only lives on your computer. If you want to open it from your phone or share it with a friend, you need to "host" it.

The easiest way for a beginner is **Netlify Drop**:
1.  Go to **[Netlify Drop](https://app.netlify.com/drop)**.
2.  Drag your entire `finance-tracker` folder and drop it into the box on the website.
3.  Wait a few seconds, and Netlify will give you a public URL (like `https://shiny-donut-12345.netlify.app`).
4.  Open that link on any device!
