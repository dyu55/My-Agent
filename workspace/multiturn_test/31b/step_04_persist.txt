### 💡 为什么之前的数据会“消失”？

之前的方案是 **Streamlit (Python)**。它的工作原理是：代码运行在云端服务器上，数据存在服务器的文件里。
当你关闭浏览器，数据其实还在服务器上，但如果你在 Replit 中使用了临时环境，或者想要一个**完全不需要登录账号、不需要联网、双击就能打开**的工具，那么 Python 方案就不合适了。

**因为 Python 必须在“服务器”上运行，而浏览器本身只能直接运行 HTML/JS。**

### 🚀 终极解决方案：纯本地网页版 (HTML + JavaScript)

为了实现你要求的 **“存到浏览器里”** 且 **“不需要服务器”**，我们需要切换到【方案三】。

我会为你写一个**单文件网页**。你只需要把它保存在你的电脑上，用浏览器打开即可。它使用浏览器自带的 `localStorage`（本地存储）功能——这就像是浏览器给每个网站开的一个小型私人仓库，**只要你不清理浏览器缓存，数据永远在你的电脑里，不会上传到任何服务器。**

#### 🛠️ 操作步骤（非常简单）：

1.  在你的电脑桌面（或任何文件夹）**新建一个文本文档**（.txt 文件）。
2.  把下面这段代码**全部复制**并粘贴进去。
3.  保存文件，然后将文件名从 `新建文本文档.txt` **重命名为 `财务管家.html`** (注意后缀必须是 `.html`)。
4.  **双击这个文件**，它会直接用你的默认浏览器打开。

<script>
    // --- 配置 ---
    const BUDGET = 5000; 
    const CATEGORIES = {
        "支出": ["餐饮", "交通", "购物", "娱乐", "房租/水电", "医疗", "其他支出"],
        "收入": ["工资", "奖金", "投资", "红包", "其他收入"]
    };

    // --- 初始化 ---
    document.getElementById('date').valueAsDate = new Date();
    updateCategories();

    // 从本地存储加载数据
    let records = JSON.parse(localStorage.getItem('myFinanceData')) || [];

    function updateCategories() {
        const type = document.getElementById('type').value;
        const catSelect = document.getElementById('category');
        catSelect.innerHTML = '';
        CATEGORIES[type].forEach(cat => {
            const opt = document.createElement('option');
            opt.value = cat;
            opt.innerHTML = cat;
            catSelect.appendChild(opt);
        });
    }

    function addRecord() {
        const date = document.getElementById('date').value;
        const type = document.getElementById('type').value;
        const category = document.getElementById('category').value;
        const amount = parseFloat(document.getElementById('amount').value);
        const note = document.getElementById('note').value;

        if (!date || isNaN(amount) || amount <= 0) {
            alert("请填写正确的日期和金额！");
            return;
        }

        const record = {
            date,
            type,
            category,
            amount: type === "收入" ? amount : -amount,
            note
        };

        records.push(record);
        localStorage.setItem('myFinanceData', JSON.stringify(records));
        
        // 清空输入框
        document.getElementById('amount').value = '';
        document.getElementById('note').value = '';
        
        render();
    }

    function clearAll() {
        if (confirm("确定要删除所有记录吗？此操作不可撤销！")) {
            records = [];
            localStorage.removeItem('myFinanceData');
            render();
        }
    }

    function render() {
        const tbody = document.getElementById('table-body');
        tbody.innerHTML = '';
        
        let totalBalance = 0;
        let mIncome = 0;
        let mExpense = 0;

        const now = new Date();
        const currentMonth = now.getMonth();
        const currentYear = now.getFullYear();

        // 排序：日期最近的在上面
        const sortedRecords = [...records].sort((a, b) => new Date(b.date) - new Date(a.date));

        sortedRecords.forEach(r => {
            totalBalance += r.amount;
            
            const rDate = new Date(r.date);
            if (rDate.getMonth() === currentMonth && rDate.getFullYear() === currentYear) {
                if (r.amount > 0) mIncome += r.amount;
                else mExpense += Math.abs(r.amount);
            }

            const row = `<tr>
                <td>${r.date}</td>
                <td>${r.category}</td>
                <td>${r.note}</td>
                <td class="${r.amount > 0 ? 'amt-positive' : 'amt-negative'}">
                    ${r.amount > 0 ? '+' : ''}${r.amount.toFixed(2)}
                </td>
            </tr>`;
            tbody.innerHTML += row;
        });

        // 更新统计
        document.getElementById('total-balance').innerText = `￥${totalBalance.toFixed(2)}`;
        document.getElementById('month-income').innerText = `￥${mIncome.toFixed(2)}`;
        document.getElementById('month-expense').innerText = `￥${mExpense.toFixed(2)}`;
        document.getElementById('month-net').innerText = `￥${(mIncome - mExpense).toFixed(2)}`;

        // 预算警告逻辑
        const warningDiv = document.getElementById('budget-warning');
        if (mExpense > BUDGET) {
            warningDiv.style.display = 'block';
            document.getElementById('warning-text').innerText = `本月已支出 ￥${mExpense.toFixed(2)}，超过预算 ￥${(mExpense - BUDGET).toFixed(2)}`;
        } else {
            warningDiv.style.display = 'none';
        }
    }

    // 首次加载运行
    render();
</script>

</body>
</html>

### 🌈 这个新版本的神奇之处：

1.  **无需服务器/无需联网**：你不需要 Replit，不需要 Python，不需要任何账号。这个文件就在你的电脑硬盘上。
2.  **数据持久化 (localStorage)**：我使用了浏览器提供的 `localStorage` 接口。
    *   当你点击“提交”时，数据会被转化为一段字符串，存在浏览器的内部数据库中。
    *   即使你关闭浏览器、重启电脑，只要你用同一个浏览器打开这个 `.html` 文件，数据依然在那里。
3.  **隐私性极高**：你的财务数据**从未离开过你的电脑**，没有任何数据被传输到网络上。
4.  **依然保留了你的所有需求**：
    *   收入/支出分类。
    *   本月统计看板。
    *   **5000元预算预警**（超支时会出现红色的震动警告框）。
    *   历史记录列表。

### 🚩 以后怎么管理这个工具？
*   **想修改预算？** 用“记事本”打开这个 `.html` 文件，搜索 `const BUDGET = 5000;`，把 5000 改掉，保存即可。
*   **想备份数据？** 目前数据在浏览器缓存里。如果你换了电脑或清理了浏览器所有缓存，数据会丢失。如果你需要备份，以后我可以帮你加上一个“导出为 Excel/CSV”的按钮。
