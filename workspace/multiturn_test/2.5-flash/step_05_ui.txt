好的，完全没问题！让界面更温馨、更适合家庭记账，并且在手机上也能有良好的体验，这些都可以通过优化 CSS 样式来实现。

我将为你重新设计一套新的 CSS 样式，并对现有 HTML 结构进行微调以更好地支持响应式布局和新样式。

### **设计思路：**

*   **色调：** 选用柔和的米白、浅灰作为背景，搭配温暖的木质棕色、柔和的绿色/蓝色作为强调色，营造温馨、舒适的家庭氛围。
*   **字体：** 选用易读、亲和力强的字体。
*   **布局：** 保持简洁明了，信息区域块状化，减少视觉混乱。
*   **响应式：** 使用 `@media` 查询，确保在手机等小屏幕设备上布局能够自动调整，按钮和输入框尺寸合适，内容不溢出。
*   **交互：** 按钮和输入框在悬停/聚焦时有轻微反馈。

    <script>
        // JavaScript 代码与之前相同，无需修改
        // 全局变量，用于存储所有交易记录
        let transactions = [];
        // 每月预算，你可以修改这个值
        const MONTHLY_BUDGET = 5000; 

        // 获取DOM元素
        const balanceDisplay = document.getElementById('current-balance');
        const transactionForm = document.getElementById('transaction-form');
        const transactionsBody = document.getElementById('transactions-body');
        const dateInput = document.getElementById('date');

        // 月度统计元素
        const monthlyIncomeDisplay = document.getElementById('monthly-income');
        const monthlyExpenseDisplay = document.getElementById('monthly-expense');
        const monthlyBalanceDisplay = document.getElementById('monthly-balance');
        const budgetAlert = document.getElementById('budget-alert');

        // --- 辅助函数 ---

        // 格式化金额，保留两位小数
        function formatAmount(amount) {
            return parseFloat(amount).toFixed(2);
        }

        // 获取当前月份的字符串，格式为 YYYY-MM
        function getCurrentMonthString() {
            const today = new Date();
            const year = today.getFullYear();
            const month = String(today.getMonth() + 1).padStart(2, '0'); // getMonth() 返回 0-11
            return `${year}-${month}`;
        }

        // --- 数据操作与存储 (核心修改点) ---

        // 从 localStorage 加载交易记录
        function loadTransactions() {
            const storedTransactions = localStorage.getItem('transactions');
            if (storedTransactions) {
                transactions = JSON.parse(storedTransactions);
            } else {
                transactions = []; // 如果没有数据，初始化为空数组
            }
        }

        // 保存交易记录到 localStorage
        function saveTransactions() {
            localStorage.setItem('transactions', JSON.stringify(transactions));
        }

        // --- 核心功能函数 ---

        // 计算并显示总余额
        function updateBalance() {
            let totalBalance = 0;
            transactions.forEach(transaction => {
                if (transaction.type === 'income') {
                    totalBalance += transaction.amount;
                } else {
                    totalBalance -= transaction.amount;
                }
            });
            balanceDisplay.textContent = formatAmount(totalBalance);
        }

        // 渲染交易列表
        function renderTransactions() {
            transactionsBody.innerHTML = ''; // 清空现有列表
            transactions.forEach((transaction, index) => {
                const row = transactionsBody.insertRow();
                const typeCell = row.insertCell(0);
                const amountCell = row.insertCell(1);
                const categoryCell = row.insertCell(2);
                const dateCell = row.insertCell(3);
                const descriptionCell = row.insertCell(4);
                const actionCell = row.insertCell(5);

                typeCell.textContent = transaction.type === 'income' ? '收入' : '支出';
                typeCell.classList.add(transaction.type === 'income' ? 'income-text' : 'expense-text');
                
                amountCell.textContent = formatAmount(transaction.amount);
                amountCell.classList.add(transaction.type === 'income' ? 'income-text' : 'expense-text');

                categoryCell.textContent = transaction.category;
                dateCell.textContent = transaction.date;
                descriptionCell.textContent = transaction.description;

                const deleteButton = document.createElement('button');
                deleteButton.textContent = '删除';
                deleteButton.classList.add('delete-btn'); // 添加一个类，方便样式控制
                deleteButton.onclick = () => deleteTransaction(index);
                actionCell.appendChild(deleteButton);
            });
        }

        // 删除交易记录
        function deleteTransaction(index) {
            if (confirm('确定要删除这笔记录吗？')) {
                transactions.splice(index, 1); // 从数组中删除
                saveTransactions(); // 删除后保存
                initApp(); // 重新加载和更新所有数据
            }
        }

        // 计算并显示月度统计
        function updateMonthlySummary() {
            const currentMonth = getCurrentMonthString();
            let monthlyIncome = 0;
            let monthlyExpense = 0;

            transactions.forEach(transaction => {
                // 检查交易日期是否属于当前月份
                if (transaction.date.startsWith(currentMonth)) {
                    if (transaction.type === 'income') {
                        monthlyIncome += transaction.amount;
                    } else {
                        monthlyExpense += transaction.amount;
                    }
                }
            });

            const monthlyBalance = monthlyIncome - monthlyExpense;
            const remainingBudget = MONTHLY_BUDGET - monthlyExpense;

            monthlyIncomeDisplay.textContent = formatAmount(monthlyIncome);
            monthlyExpenseDisplay.textContent = formatAmount(monthlyExpense);
            monthlyBalanceDisplay.textContent = formatAmount(monthlyBalance);

            // 预算提醒
            budgetAlert.classList.remove('over', 'within'); // 清除之前的样式
            if (remainingBudget < 0) {
                budgetAlert.textContent = `🚨 预算超支 ${formatAmount(Math.abs(remainingBudget))} 元！请注意。`;
                budgetAlert.classList.add('over');
            } else {
                budgetAlert.textContent = `本月预算剩余 ${formatAmount(remainingBudget)} 元。`;
                budgetAlert.classList.add('within');
            }
        }

        // 根据选择的类型更新类别下拉框的可用选项
        function updateCategoryOptions(type) {
            const categorySelect = document.getElementById('category');
            const currentSelectedValue = categorySelect.value;
            
            Array.from(categorySelect.children).forEach(optgroup => {
                if (optgroup.tagName === 'OPTGROUP') {
                    if (optgroup.label === '收入' && type === 'expense') {
                        optgroup.style.display = 'none';
                    } else if (optgroup.label === '支出' && type === 'income') {
                        optgroup.style.display = 'none';
                    } else {
                        optgroup.style.display = ''; // 显示对应类别
                    }
                }
            });

            let foundCurrent = false;
            for (let i = 0; i < categorySelect.options.length; i++) {
                const option = categorySelect.options[i];
                if (option.value === currentSelectedValue && option.parentNode.style.display !== 'none') {
                    foundCurrent = true;
                    break;
                }
            }
            
            if (!foundCurrent) {
                for (let i = 0; i < categorySelect.options.length; i++) {
                    const option = categorySelect.options[i];
                    if (option.parentNode.style.display !== 'none') {
                        categorySelect.selectedIndex = i;
                        break;
                    }
                }
            }
        }


        // --- 事件监听 ---

            const category = document.getElementById('category').value;

            const description = document.getElementById('description').value.trim();

            if (isNaN(amount) || amount <= 0) {
                alert('请输入有效的金额！');
                return;
            }

            const newTransaction = {
                type,
                amount,
                category,
                date,
                description,
                id: Date.now() // 为每笔交易生成一个唯一ID，方便将来操作
            };

            transactions.push(newTransaction);
            saveTransactions(); // 添加后保存
            transactionForm.reset(); // 清空表单
            // 重置类型选择和类别
            document.getElementById('type-income').checked = true;

### **主要修改点解释：**

1.  **HTML 结构调整：**
    *   引入了 Google Fonts 的 Noto Sans SC（思源黑体），让中文字体显示更美观。
    *   将总余额和月度概览都包裹在 `summary-card` class 的 `div` 中，统一卡片风格。
    *   添加了 `main-content`、`left-panel`、`right-panel` `div`，用于实现左右分栏布局。
    *   为交易列表的表格添加了 `overflow-x: auto;` 的 `div` 包裹，防止在手机上表格过宽溢出。
    *   给 `strong` 标签添加了 `income` 和 `expense` 类，方便 CSS 赋予颜色。
2.  **CSS 样式更新：**
    *   **CSS 变量 (`:root`)：** 定义了颜色、字体、阴影等变量，方便日后修改和保持一致性。

    *   **表单美化：** 输入框、下拉框、按钮都做了圆角、阴影和聚焦效果。
    *   **自定义单选按钮：** 让收入/支出选择的单选按钮更美观。
    *   **表格样式：** 增加了表格的圆角、条纹效果和悬停高亮。
    *   **响应式设计 (`@media`)：**

        *   在宽度小于 480px 时（更小的手机），会进一步隐藏“日期”列，只保留最核心的信息，确保在小屏幕上依然可用。
3.  **JavaScript 调整：**
    *   在 `renderTransactions` 函数中，为金额和类型文字添加了 `income-text` 或 `expense-text` 类，这样 CSS 就可以根据这些类来设置颜色了。
