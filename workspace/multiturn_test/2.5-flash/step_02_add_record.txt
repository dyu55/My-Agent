没问题！我们先来搭建网页的骨架，也就是 HTML 部分。这部分代码定义了你页面上会看到的所有元素，比如标题、输入框、按钮等等。

根据你的需求，我来为你设计第一个版本的 HTML 代码，它包含：

1.  **页面标题**
2.  **当前余额显示区**（暂时是 0，将来会实时更新）
3.  **添加记录表单**：
    *   选择**类型**（收入/支出）的单选按钮
    *   **金额**输入框
    *   **类别**下拉选择框（预设了一些收入和支出类别，你可以后续自定义）
    *   **日期**选择器（默认显示今天日期）
    *   **备注**文本框
    *   **提交**按钮
4.  **历史交易列表区**（暂时为空，将来会显示你添加的记录）

---

### **第一步：创建 HTML 文件**

请你按照以下步骤操作：

1.  在你的电脑上，找到一个你希望保存这个工具的文件夹。
2.  在这个文件夹里，右键点击 -> 新建 -> 文本文档。
3.  把新建的文本文档命名为 `index.html`。**注意：确保文件后缀是 `.html`，而不是 `.txt`。** 如果你看不到 `.txt` 后缀，可能需要到文件夹选项里设置显示文件扩展名。
4.  用记事本（Windows）或者任何文本编辑器（如 Sublime Text, VS Code 等，如果你有安装的话）打开这个 `index.html` 文件。
5.  将下面我提供的所有代码复制粘贴进去，然后保存文件。

    <script>
        // 当页面加载完成后执行
        document.addEventListener('DOMContentLoaded', () => {
            const dateInput = document.getElementById('date');
            // 设置日期输入框的默认值为今天
            const today = new Date();
            const year = today.getFullYear();
            // getMonth() 返回 0-11，所以要加 1
            const month = String(today.getMonth() + 1).padStart(2, '0');
            const day = String(today.getDate()).padStart(2, '0');
            dateInput.value = `${year}-${month}-${day}`;
            
            // 默认选中收入，并根据类型调整类别选择
            document.getElementById('type-income').checked = true;
            updateCategoryOptions('income');

            // 监听类型（收入/支出）选择的变化
            document.querySelectorAll('input[name="transaction-type"]').forEach(radio => {
                radio.addEventListener('change', (event) => {
                    updateCategoryOptions(event.target.value);
                });
            });
        });

        // 根据选择的类型更新类别下拉框的可用选项
        function updateCategoryOptions(type) {
            const categorySelect = document.getElementById('category');
            // 遍历所有 optgroup
            Array.from(categorySelect.children).forEach(optgroup => {
                if (optgroup.tagName === 'OPTGROUP') {
                    if (optgroup.label === '收入' && type === 'expense') {
                        optgroup.style.display = 'none'; // 隐藏收入类别
                    } else if (optgroup.label === '支出' && type === 'income') {
                        optgroup.style.display = 'none'; // 隐藏支出类别
                    } else {
                        optgroup.style.display = ''; // 显示对应类别
                    }
                }
            });
            // 确保当前选中的类别是可见的，如果不是，则默认选择第一个可见项
            if (categorySelect.options[categorySelect.selectedIndex] && categorySelect.options[categorySelect.selectedIndex].parentNode.style.display === 'none') {
                for (let i = 0; i < categorySelect.options.length; i++) {
                    if (categorySelect.options[i].parentNode.style.display !== 'none') {
                        categorySelect.selectedIndex = i;
                        break;
                    }
                }
            }
        }

        // 暂时留空，后续填充更多JavaScript功能
    </script>

### **第二步：在浏览器中打开**

1.  保存 `index.html` 文件后，回到你保存文件的文件夹。
2.  双击 `index.html` 文件。
3.  它应该会在你的默认网页浏览器（如 Chrome, Edge, Firefox 等）中打开。

你现在应该能看到一个基本的页面，上面有标题、当前余额（0元）、一个表单以及一个空的交易记录表格。表单中的日期会默认显示今天，并且选择“收入”或“支出”时，下方的“类别”下拉框会自动显示对应的类别选项。

你现在已经有了一个页面的基本骨架和一些简单的样式了。
